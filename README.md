# frankzshy.github.io

Personal academic website of Shihangyin (Frank) Zhang, built with [academicpages](https://github.com/academicpages/academicpages.github.io), a Jekyll theme forked from [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/).

Site content lives in `_pages/` (About, CV), `_publications/`, and `_teaching/`. Site-wide settings are in `_config.yml`.

Live at: https://frankzshy.github.io
